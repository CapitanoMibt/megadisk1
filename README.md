# MegaDisk Ultimate 🚀

Мощная утилита для диагностики и обслуживания дисков (HDD, SSD, NVMe, USB) в Windows. 
Заменяет собой CrystalDiskInfo, CrystalDiskMark и базовые функции DiskGenius.

## ⚡ Возможности
- **S.M.A.R.T.** — мониторинг здоровья, температуры и график в реальном времени.
- **Тесты скорости** — SEQ и RND (4K) чтение/запись (как в CrystalDiskMark).
- **Карта поверхности** — цветовая визуализация состояния секторов (поиск бэдов).
- **Клонирование и образы** — создание `.img` дампов и копирование диск-в-диск.
- **Восстановление файлов** — поиск потерянных JPEG и PDF сигнатур.
- **Hex-редактор** — просмотр сырых секторов (MBR/LBA).
- **Secure Erase** — безопасное стирание данных.
- **Тёмная и светлая темы**.

## 🛠 Установка
1. Скачайте `MegaDisk.exe` из раздела **Releases**.
2. Запустите файл **от имени администратора** (обязательно для доступа к дискам).
3. Утилита `smartctl` уже встроена в программу!

## ⚠️ Внимание
Некоторые функции (Клонирование, Стирание, Тест записи) **уничтожают данные**. Используйте их с осторожностью на свой страх и риск.
